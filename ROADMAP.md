# 🗺️ ROADMAP - Карта развития проекта SketchCodeCompose

## 📋 Концепция проекта

**SketchCodeCompose** — визуальный редактор HTML/CSS, который позволяет создавать веб-страницы рисуя элементы на холсте (как в Miro), а система автоматически генерирует чистый, читаемый HTML и CSS код.

**Ключевые принципы:**
- ✅ Генерация ванильного HTML/CSS (без обёрток и скрытых данных)
- ✅ Код должен быть понятен и редактируем вручную
- ✅ Гибкость кода важнее простоты использования
- ✅ Семантическая разметка и обучение пользователей
- ✅ Модульный CSS (отдельный файл для каждого класса)

## ✅ Что уже готово (v0.1.0)

### Архитектура
- [x] Vue 3 + Vite + Pinia
- [x] JavaScript (без TypeScript)
- [x] Модульная структура проекта
- [x] Конфигурация и константы

### Stores (Pinia)
- [x] `projectStore` - управление проектом и элементами
- [x] `canvasStore` - состояние холста (zoom, pan, grid)
- [x] `selectionStore` - выделение элементов
- [x] `settingsStore` - настройки пользователя
- [x] `layoutStore` - режимы отображения панелей
- [x] `editorStore` - открытые файлы в редакторе

### Модели данных
- [x] `Element` - модель элемента с относительным позиционированием
- [x] `Project` - модель проекта с иерархией элементов

### UI компоненты
- [x] `AppLayout` - адаптивная система панелей
- [x] `ResizeHandle` - изменение размера панелей (Pinia архитектура)
- [x] `BurgerMenu` - навигация и настройки
- [x] `FloatingToolbar` - плавающая панель инструментов на Canvas
- [x] Панели: Canvas, Properties, Tree, Code

### Layout режимы
- [x] **Default** (40% Canvas | 20% Properties/Tree | 40% Code)
- [x] **Designer** (70% Canvas | 30% Properties)
- [x] **Developer** (35% Canvas | 15% Properties | 15% Tree | 35% Code)
- [x] **Mini** (переключение между Canvas/Properties ↔ Code/Tree)

### Composables
- [x] `useMenu` - управление Burger Menu
- [x] `useKeyboard` - горячие клавиши
- [x] `useAutoSave` - автосохранение
